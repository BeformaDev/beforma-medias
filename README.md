# Médias publics de beforma.fr

Vidéos affichées sur le site beforma.fr, distribuées par le CDN jsDelivr pour une lecture fluide partout (métropole, La Réunion, Mayotte).

- `video/melanie-accueil-480.mp4` : témoignage de Mélanie, 37 s, version téléphone
- `video/melanie-accueil-720.mp4` : même vidéo, version ordinateur
- `video/entrepreneur-tpe-ia-90s-480.mp4` : présentation « Entrepreneur de la TPE de l'IA », 86 s, version téléphone (depuis v2)
- `video/entrepreneur-tpe-ia-90s-720.mp4` : même vidéo, version ordinateur (depuis v2)
- `video/entrepreneur-tpe-70s-480.mp4` : présentation « Entrepreneur de TPE » (6 mois et intensif), 71 s, version téléphone (depuis v3)
- `video/entrepreneur-tpe-70s-720.mp4` : même vidéo, version ordinateur (depuis v3)

Lien type : `https://cdn.jsdelivr.net/gh/BeformaDev/beforma-medias@<version>/video/<fichier>`

Ne contient que des fichiers déjà publics sur le site. Le code du site est dans un autre dépôt, privé.
